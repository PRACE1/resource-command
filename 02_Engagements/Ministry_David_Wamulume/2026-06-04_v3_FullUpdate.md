**What Resource Command actually does and how it fits with existing systems**

This is the part I want to be clearest about, because I expect it to be the first question asked when this email is forwarded.

The existing audit, inspection, and enforcement systems in Zambia do important work. Resource Command does not replace any of them. It adds a layer underneath them.

What our system does is use satellite data, on-site sensor readings, and cryptographic verification to independently confirm whether an operator's declared production is mathematically consistent with the physical evidence. It does this without exposing the operator's commercial data and without interfering with anyone's existing process. An operator still files their declaration the way they always have. The auditor still audits the way they always have. Our system simply provides an automatic, continuous, independent check that runs in the background and flags inconsistencies before they reach the audit stage.

In other words: the existing systems answer the question "did the operator file their paperwork correctly?" Resource Command answers the question "is what they filed actually true?" Both questions need to be answered. Today only the first one is.
